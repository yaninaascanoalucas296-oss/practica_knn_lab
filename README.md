# SENATI / KNN Lab — Laboratorio de Predicción Inteligente

Aplicación web local en Python (`pandas` + `scikit-learn`) con la interfaz **SENATI / KNN Lab** para los dos ejercicios de la Práctica Calificada:

1. **01 - Satisfacción del cliente:** Predice si un cliente está satisfecho (`SÍ`) o no (`NO`) con un servicio brindado.
2. **02 - Inversión en software:** Predice si un empresario invierte (`SÍ`) o no (`NO`) en el desarrollo de un software para automatizar sus procesos.

## Ejecución rápida

1. Instala dependencias (si aún no las tienes):
   ```bash
   python -m pip install -r requirements.txt
   ```
2. Ejecuta el servidor:
   ```bash
   python app.py
   ```
3. Abre en tu navegador: `http://127.0.0.1:5000` (también incluye fallback automático en el navegador por si abres `index.html` directamente).
